# Plan Builder

Transform task analysis into executable plans with clear steps, milestones, and success criteria.

## When to Use This Skill

- After completing task analysis
- When converting goals into action items
- When coordinating multiple workstreams
- When tracking progress against objectives

## Planning Approach

### 1. Define Success
- What does "done" look like?
- What are the measurable outcomes?
- What are the acceptance criteria?

### 2. Sequence Steps
- Order tasks by dependencies
- Identify parallel workstreams
- Estimate duration for each step

### 3. Set Milestones
- Mark key decision points
- Define checkpoints for validation
- Establish progress indicators

### 4. Allocate Resources
- Assign responsibilities
- Identify required tools/skills
- Note external dependencies

### 5. Plan for Contingencies
- Identify decision branches
- Define fallback options
- Note risk mitigation strategies

## Plan Structure

See templates.md for standard formats.

## Best Practices

- Keep plans flexible and adaptable
- Make success criteria explicit
- Include verification steps
- Document assumptions
- Plan for learning and iteration
