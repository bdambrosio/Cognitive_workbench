# Plan Templates

## Simple Sequential Plan

```
Plan: [Goal Name]
Target: [Completion criteria]

Steps:
1. [Step 1] - [estimated time]
2. [Step 2] - [estimated time]
3. [Step 3] - [estimated time]

Success: [How to verify completion]
```

## Complex Multi-Track Plan

```
Plan: [Goal Name]

Track A: [Component name]
- Step A1
- Step A2
- Milestone: [Checkpoint]

Track B: [Component name]
- Step B1
- Step B2
- Milestone: [Checkpoint]

Integration:
- After A2 and B2: [Integration step]
- Final validation: [Verification]

Success Criteria:
1. [Criterion 1]
2. [Criterion 2]
```

## Iterative Plan

```
Plan: [Goal Name]

Iteration 1 (MVP):
- Goals: [Minimal functionality]
- Steps: [Quick path to testable result]
- Validation: [What to check]

Iteration 2 (Enhancement):
- Goals: [Added features]
- Steps: [Building on iteration 1]
- Validation: [What to check]

Iteration N:
- [Continue as needed]
```
