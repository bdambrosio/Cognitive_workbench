# Word Count

Counts the number of words in input text.

## Purpose

Simple deterministic word counting for text analysis.

## Input Format

Accepts:
- Plain text string

## Output Format

Returns string with word count.

## Example

Input: "Hello world this is a test"
Output: "Word count: 6"
