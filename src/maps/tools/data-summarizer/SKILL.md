# Data Summarizer

Synthesize information from various sources into clear, actionable insights.

## When to Use This Skill

- When reviewing large amounts of information
- When extracting key points from documents
- When identifying patterns in data
- When preparing executive summaries

## Summarization Approach

### 1. Identify Core Content
- What is the main message?
- What are the key facts or findings?
- What decisions or actions are implied?

### 2. Extract Patterns
- What themes emerge?
- What relationships exist?
- What trends are visible?

### 3. Distill Insights
- What's important vs. interesting?
- What's actionable?
- What's surprising or unexpected?

### 4. Structure Output
- Lead with most important information
- Group related concepts
- Provide context where needed
- Note limitations or uncertainties

## Summary Formats

### Executive Summary
- **Key Finding**: [One sentence main point]
- **Details**: [2-3 supporting points]
- **Implications**: [What this means]
- **Recommendation**: [What to do]

### Bullet Point Summary
- [Key point 1]
- [Key point 2]
- [Key point 3]
- [Action items or next steps]

### Structured Analysis
- **Context**: [Background]
- **Findings**: [What was discovered]
- **Patterns**: [Recurring themes]
- **Gaps**: [What's missing]
- **Conclusions**: [Synthesis]

## Best Practices

- Preserve accuracy while reducing detail
- Maintain source attribution
- Flag assumptions or uncertainties
- Scale summary depth to audience need
- Separate facts from interpretations
