# X teaser — essay 1

Written as a thread, not an excerpt. No section references, no standards
vocabulary, nothing that needs the essay to parse. Each post should survive
being screenshotted alone.

Opens on the truncation failure rather than the thesis: it is the only part of
the piece that a reader might be suffering from right now without knowing.

---

**1/**

For months my audit agent worked from a method document it had never read past
section 2 of 16.

The tool that fetched it capped the observation. It ended mid-sentence.

Nothing errored. No log line said "truncated." The reports looked like reports.

**2/**

The failure was invisible from both ends. The file was complete on disk. The
model gave no sign of working from a fragment.

Moving the same file into the system prompt made the rest reachable — and three
contract elements appeared in output for the first time.

**3/**

Identical content. Different delivery. Different behaviour.

Which matters, because everything interesting in that document lives in the
part the agent never saw.

**4/**

That document has no boxes and no arrows. It never says what to do next.

A script specifies transitions.
A method specifies acceptance.

Every clause in a script answers *what happens next?* Every clause in a method
answers *what would make this acceptable?*

**5/**

Only one of those survives contact with an executor that has judgement.

For thirty years the executor was a machine, so we wrote scripts. The executor
changed. Most people are still writing for the old one.

**6/**

Here is where specification runs out.

Same nine documents. Same method. Three models enumerated the claim surface at
62, 67 and 273 claims.

Every coverage figure in the report divides by that number.

**7/**

Tightening the definition makes it worse.

"One claim is one assertion that can take exactly one verdict" reads as
precise. It has no fixed size.

New spread: 44, 21, 321.

**8/**

The fix is not a better definition. It is a different kind of clause.

The engagement names which documents carry the seller's claims. The auditor is
told, not asked to infer.

Result: 33, 70, 88 — and two models citing an identical set of 21 document
lines.

**9/**

They agree about where the claims are. They differ on how finely to slice them.

The first was a defect in the criteria. The second is grain, and it costs
nothing.

A method's reach ends where its author's knowledge of the specific engagement
ends.

**10/**

One honest limit: a specification constrains form. It does not confer
competence.

Give a derived finding its own format and models use it, every run. What they
put in it varies — the same two arithmetic findings recovered 1 of 2, 2 of 2,
1 of 2.

**11/**

Anyone selling you "we improved the prompt and the model got smarter" is
describing something that did not happen.
