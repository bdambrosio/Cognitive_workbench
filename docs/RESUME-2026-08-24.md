## Decisions made yesterday, so they are not re-litigated

- **Scope is priced in claims, not repository size.** Up to N prioritised
  claims, explicit coverage on the rest. Settled empirically: code went 0 →
  255K lines while the claim surface grew ~4x.
- **The deliverable is professional judgement produced with tooling.** Machine
  reads/searches/drafts; human confirms, corrects, signs. That is what §10's
  posture requires and what justifies $5K.
- **Model targeting is output-tokens-per-call, not parameters.** This
  architecture makes 35–187 model calls per audit, so per-call latency is
  multiplied by that. Qwen3.8-2.4T spends 2,902 tokens answering a one-line
  question where DeepSeek spends 18 — unusable regardless of quality. Viable
  today: local Qwen-27B (free), Luna, DeepSeek-V4-Flash.
- **The superlarge tier is out of scope**, not pending.
- **Target redaction**: ChatterMate is named internally, redacted in anything
  shown to a prospect.

## Open engineering, none of it blocking

- **Deliverables produced via `display` are not persisted.** Cost two-thirds
  of the Body audit report permanently. The last unfixed instance of the
  session's recurring shape: evidence retrieved, then lost in transit.
- **`unsupported` cannot be measured in one grading pass** — three passes over
  identical text gave 1, 0, 2. Any threshold result within one claim of the
  boundary needs majority-of-three. The gate currently coin-flips there.
- **The provenance gate drops true negative facts.** "The word 'sentiment'
  does not appear in chat_agent.py" fails the verbatim-quote check because a
  negative fact cannot be a quote. Matters before §12 step 6b becomes a
  delivery gate — as configured it would strip the findings needing most
  support.
- **NOTE lines are stripped from stored traces** (`chat_loop.py:1667` keeps
  only `$step*`), so no post-hoc analysis can tell whether an agent was warned
  before running out of iterations.

## The lesson worth carrying

Three failures yesterday had one shape: **evidence was retrieved and then lost
in transit.** The §9 taxonomy died in a capped observation; the Gap Map and
Body report died in unsaved canvas renders; the sentiment evidence died in a
`max_iters` diagnostic that discarded a working log containing the answer.
Retrieval was never the weak link. Two are fixed; the display one is not.

Corollary, learned expensively: **read the trace before theorising.** That
single error was misdiagnosed three times — including once by the agent about
itself — and the trace said plainly what happened the whole time.
