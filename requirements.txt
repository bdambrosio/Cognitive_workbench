# System binary dependencies (NOT pip-installable):
#
#   ripgrep — required by the chat `inspect` / `inspect_external`
#     subagents. Install: `apt install ripgrep` (Debian/Ubuntu),
#     `brew install ripgrep` (macOS), or
#     https://github.com/BurntSushi/ripgrep
#     The subagent fails with an ERROR-tagged observation if `rg` is
#     not on PATH at call time.
#
#   nmap — required by the chat `security` subagent. Install:
#     `apt install nmap` / `brew install nmap`. The subagent
#     surfaces ERROR observations if `nmap` is missing.
#
#   chromium / google-chrome — required for the --affect and --canvas
#     widget windows (the launcher opens them in --app= mode).
#     Auto-detects google-chrome, chromium, brave-browser, microsoft-edge.
#     Override with --browser <path>. The widget bridge still runs
#     without a browser; the launcher just logs a warning.
#
#   Playwright browsers — `playwright install chromium` populates the
#     headless browser used by fetch_text as a SPA fallback. Without
#     it, fetch_text degrades to the HTML/HTTP path.
