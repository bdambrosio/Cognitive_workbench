The AI agent can answer customers using a self-hosted model, with no customer conversation sent to an outside AI provider.
Customer conversation data is encrypted at rest in the database.
A customer's conversations and personal data can be deleted on request by a function in the software.
The backend can run as more than one instance behind a load balancer.
The Shopify integration requests only read access to store data.
