294|### 6.1 `motor_controller`
295|
296|**Responsibility:** Translate velocity commands into PWM output. Read encoders. Publish odometry.
297|
298|**Hardware ownership:** MDD10A (4 GPIO pins), encoder inputs (4 GPIO pins).
299|
300|**Loop structure:**
301|- Main loop at 50 Hz (20ms cycle).
302|- Each cycle: read encoders → compute odometry → check for cmd timeout → compute PWM from latest command → write GPIO → publish odom and motor_state.
303|- Zenoh subscription callback for `cmd_vel`, `cmd_direct`, `emergency_stop` sets shared state variables (protected by a simple lock since callbacks run on Zenoh's internal thread).
304|
305|**Differential drive math:**
306|```
307|wheel_base = W  (meters, measured)
308|wheel_radius = R  (meters, measured)
309|
310|From cmd_vel (linear v, angular ω):
311|  v_left  = v - (ω * W / 2)
312|  v_right = v + (ω * W / 2)
313|
314|PWM mapping:
315|  pwm = clamp(velocity / max_wheel_velocity, -1.0, 1.0)
316|  direction = "fwd" if pwm >= 0 else "rev"
317|  duty_cycle = abs(pwm)
318|```
319|
320|**Odometry integration:**
321|```
322|From encoder ticks since last cycle:
323|  d_left  = left_ticks * (2π * R / ticks_per_revolution)
324|  d_right = right_ticks * (2π * R / ticks_per_revolution)
325|  d_center = (d_left + d_right) / 2
326|  d_theta  = (d_right - d_left) / W
327|
328|  x     += d_center * cos(theta + d_theta/2)
329|  y     += d_center * sin(theta + d_theta/2)
330|  theta += d_theta
331|```
332|

493|## 10. Open Questions
