# DOCUMENT 2: TECH STACK DESCRIPTION (as provided by seller)

FlowMetrics is built on a standard, modern SaaS stack designed for reliability and ease of maintenance. The core application is a Rails 7 application hosted on Heroku, which provides automatic scaling and failover capabilities at the platform level. This ensures that the application remains available even under varying load conditions, with no manual intervention required for routine operations.

Data persistence is handled by PostgreSQL, which is configured with daily scheduled backups to ensure data integrity and recoverability. We utilize Redis for session caching to improve response times and user experience. Payment processing is securely handled through Stripe, which supports both credit card transactions and recurring billing. For our product intelligence features, we integrate with a third-party data enrichment API that provides real-time product data, allowing our users to make informed decisions about their inventory and pricing. The entire stack is managed through Heroku's dashboard, ensuring that deployments, scaling, and monitoring are streamlined and efficient. We consider this a standard SaaS stack with platform-level redundancy, allowing us to focus on product development rather than infrastructure management.
