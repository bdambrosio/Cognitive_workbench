3|> ChatterMate is an open-source AI customer-support chatbot platform. You can sign up, create AI
4|> agents, add knowledge sources, and embed a chat widget — all from a browser, the terminal (CLI),
5|> or programmatically via an AI agent over MCP.
6|
7|## Start here (AI agents & automation)
8|
9|Use the **ChatterMate CLI** (the `chattermate` command, installed with `pip install chattermate-cli`)
10|to sign up and manage everything from the terminal. It is the account/config CLI — distinct from the
11|self-host Docker tool (`npm install -g chattermate-deploy`).
12|
13|Minimal end-to-end flow:
14|
15|```bash
16|pip install chattermate-cli
17|chattermate signup --name "Acme Inc" --domain acme.com --admin-email you@acme.com --admin-name "You"
18|chattermate agent create --name "Support" --type customer_support -i "Be concise" --json
19|# Add knowledge from a URL or a local PDF:
20|chattermate knowledge add-url --website https://docs.acme.com --agent-id <agent-id>
21|chattermate knowledge add-file ./guide.pdf --agent-id <agent-id>
22|# Create a widget to get the embed id:
23|chattermate widget create --agent-id <agent-id> --name "Website widget"
24|# Embed on your site:
25|# <script>window.chattermateId='YOUR_WIDGET_ID';</script>
26|# <script src="https://app.chattermate.chat/webclient/chattermate.min.js"></script>
27|```
