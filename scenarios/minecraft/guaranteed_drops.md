# Guaranteed Block Drops (Java Edition)

Blocks in this list ALWAYS drop an item when broken normally,
without requiring special tools or conditions.

Use this list when a task requires guaranteed inventory change.

---

## Guaranteed Drop Blocks

- dirt → dirt
- grass_block → dirt
- stone → cobblestone
- cobblestone → cobblestone
- sand → sand
- gravel → gravel

---

## Exclusions

- Tool-specific drops are excluded (e.g. ores)
- Conditional drops are excluded (e.g. leaves → saplings)
- Partial blocks are excluded

---

## Agent Rule (Strong)

If a task requires:
> “collect the dropped item”

The block chosen MUST appear in this list.
